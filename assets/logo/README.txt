EL TEQUILA — LOGO
==================

Esta carpeta está reservada para un logo real del restaurante
(por ejemplo: logo.svg o logo.png).

Actualmente la demo usa un logotipo tipográfico ("EL TEQUILA" +
un glifo ✦) definido directamente en index.html / css/styles.css,
por lo que no requiere ningún archivo aquí para funcionar.

Si agregas un archivo de logo, puedes reemplazar el bloque:

  <div class="brand">
    <span class="brand-glyph">✦</span>
    <span class="brand-name">EL TEQUILA</span>
  </div>

en index.html por una etiqueta <img src="assets/logo/logo.svg" ...>.
